CÁCH DÙNG
1. Đóng project hiện tại trong Visual Studio.
2. Giải nén thư mục này.
3. Mở file QuanLySinhVien.csproj bằng Visual Studio 2022.
4. Nhấn F5 để chạy.

Project tạo giao diện hoàn toàn bằng code, không dùng Form Designer.
Nếu muốn chép vào project hiện tại: thêm MainForm.cs, LopHoc.cs, SinhVien.cs và thay Program.cs; Form1 có thể xóa hoặc bỏ qua.
